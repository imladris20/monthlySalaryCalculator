# 實領月薪計算機 (Monthly Salary Calculator)

這是一個輕量、免安裝、純前端打造的「實領薪資與加班費試算工具」。主要用於幫助使用者根據台灣勞基法最新（115年度）的勞保、健保級距，精準試算扣除自負額及加上加班費後的最終實領薪資。

## ✨ 核心特色

- ⚡️ **即時預覽**：輸入帳面月薪，立即動態換算您的「平日時薪」、對應的「投保級距」，以及勞健保自負額與雇主提撥的勞退金額。
- 🕒 **精準加班費計算**：
  - 前 2 小時（1~120 分鐘）：時薪 × 4/3
  - 第 3 到 4 小時（121~240 分鐘）：時薪 × 5/3
  - 支援動態新增多筆每日加班紀錄，精確計算到分鐘。
- 📊 **完整勞健保級距表**：內建最新年度完整的勞健保及勞退級距表，並在查看時**自動高亮（Highlight）**您目前所屬的級距與需負擔的金額。
- 📱 **響應式設計 (RWD)**：使用 Mobile First 策略開發，完美適配手機與桌面版畫面。
- 🎨 **現代化 UI**：採用 DaisyUI 的 `pastel` 主題，介面柔和美觀。

## 🛠 系統架構與技術棧

本專案完全依賴前端技術，無須後端伺服器，可直接透過瀏覽器開啟執行，或是部署於 GitHub Pages：

- **HTML5** & **Vanilla JavaScript** (ES6+)
- **Tailwind CSS v4** (透過 CDN 載入，零建置設定)
- **DaisyUI** (透過 CDN 載入，快速套用現代化元件庫)

## 📂 檔案結構

- `index.html`: 主要的網頁結構與版面配置。
- `style.css`: 自訂的少量樣式，主要用於動畫與修復特定表格的置頂 (Sticky) 問題。
- `script.js`: 核心邏輯，包含即時試算、加班費累加、動態 DOM 操作與 Modal 高亮功能。
- `insuranceData.js`: 內含 `INSURANCE_BRACKETS` 常數，儲存 58 階完整的勞保、健保與勞退對應級距資料。

## 🚀 如何使用

1. 將本專案 clone 到本地端：
   ```bash
   git clone https://github.com/your-username/overtimePayCalculator.git
   ```
2. 直接使用瀏覽器打開 `index.html`，或使用 VS Code 的 Live Server 擴充套件開啟。
3. **步驟說明**：
   - 在「月薪」欄位輸入您的帳面薪資。
   - 若有加班，點擊「+ 新增一日」來增加當日的加班分鐘數。
   - 點擊「開始計算」，即可查看下方整理出的勞健保扣除額、總加班費、雇主提撥勞退，以及最重要的「最終實領薪資」。
   - 若想了解扣除額細節，可點擊「依級距表扣除」中的**級距表**連結，系統會自動捲動並高亮您的級距。

## ⚠️ 注意事項

本計算結果僅供參考，實際薪資發放仍依各公司計算方式（例如全勤獎金、伙食津貼是否納入投保級距）及最新勞基法規定為準。
